# 找片、追剧与 VPS 状态

此版本新增 `/discover/`。电影墙顶部“找片 / 追剧”进入定制页面；登录使用 Emby 管理员账号。未登录、被禁用、失去管理员权限的账号不能访问搜索、资源状态或设置 API。登录会话限时 8 小时；修改操作同时校验来源和 CSRF。

## 首次连接

1. 设置 → 阿里云盘，按引导获取阿里云盘 **Open** Refresh Token，粘贴后连接。新挂载使用 `/aliyun`、`root`、资源库，在线授权参数与 OpenList 授权页匹配。原挂载只更新令牌，保留其他授权设置。
2. 尚无服务凭据时，分别填写 OpenList 管理员账号和 qB 正式账号，无需与 Emby 相同。OpenList 密码只用于本次交换管理 Token，不保存在会话中；qB 服务凭据写入私有配置，供后台下载使用。后续留空沿用，连接失效时可重新输入。
3. 点击“配置 Indexer”，在原生 Prowlarr 添加站点和凭据并 Test，返回页面刷新状态。
4. 云盘接入成功后上传器自动读入配置，无需手动重启。relay 从只读私有文件读取管理令牌，播放权限及禁止 VPS 回源的规则保持有效。

保留两个搜索入口。电影按电影分类搜索，默认 1080p、没有时显示全部，体积升序。剧集／综艺不增加电影分类限制，展示站点返回的全部资源，包含电视剧、动漫、综艺等；默认全部清晰度，可筛选清晰度、编码、站点和免费。浏览器只接收随机结果 ID，不接收私密种子链接或管理 Key。标题识别不能替代媒体探测。

电影默认筛选 1080p，当前搜索没有 1080p 时自动显示全部，资源按体积从小到大排列，显示筛选后与总结果数，可一键重置筛选查看全部资源。HDSky 与 SpringSunday 的副标题和站点徽标通过服务器使用既有索引器 Cookie 补充读取搜索列表，每站每次搜索最多补充一页，不逐条抓取详情。显示站点提供的 CMCTV、官方、合集、中字等标签；读取失败或结果不在该页时显示附加信息不完整提示，不伪造标签，不阻断原搜索结果下载。账号 Cookie、站点下载链接不返回浏览器。

## 按资源版本下载与追更

剧集／综艺结果展示完整标题、副标题、站点徽标、发布组、体积及标题中的集数范围。每条资源有两个动作：

- **下载此资源**：直接下载选中的资源，不预览或保存追剧版本、不创建或修改 Sonarr 剧集／监控；不受已有追更版本限制。无需 Sonarr 识别的综艺也可下载。合集会下载整包，不能把它当作包内选文件。
- **按此版本追更**：确认发布组、清晰度、编码、片源类型、平台、音轨／字幕标记；切换候选剧集时保留已填写的版本条件，仅当条件与已保存版本不同时才要求勾选换版确认。默认“补齐已有并持续追更”，也可选仅后续、指定季或仅选集。片源、音轨等可展开补充；逗号分隔的音轨／字幕标记必须全部满足。未识别字段实时提示，须补充或确认不限；缺少发布组时不能建立同版规则。

后台将所有已填写条件合成一条 AND 正则，保存为 Sonarr Release Profile，以每剧专属标签限定范围，作用于全部站点。同一 Profile 的多个 required 条目实际是 OR，故本包只使用一个合取表达式，不使用偏好分值。规则保存并回读验证后才开启监控；新剧的规则和标签在添加前已存在，通过原生 addOptions 在首次集数导入后发起补集，避免空元数据竞争。

只下载几个单集：**按此版本追更 → 仅选集下载 → 勾选集数**；已有有效规则的剧也可从“我的追剧”进入选集。弹窗默认定位到首个含可下载集数的季，支持一键全选或取消全选本季可下载集。只提交所选 EpisodeSearch，并继续受该剧版本规则限制；原生搜索若选择合并资源可能包含额外集数，需核对任务。加载期间显示动效并自动查询（最长 2 分钟），超时可刷新，不会因此启动整季下载。

电影与独立剧集下载均由 Prowlarr 原生缓存 GUID 提交，明确指定各自下载客户端：电影 `Cinema qB / cinema-movies`，独立剧集 `Cinema qB TV / cinema-tv`。独立剧集写入 `/media/downloads/tv-manual`，不交给 Sonarr 接管；uploader 复用视频发现、上传校验与发布流程，按原资源目录归档到 `/aliyun/TV`。自动追更继续通过 Sonarr 的 `sonarr-tv` 分类与导入目录。独立下载没有 Sonarr 元数据整理，原资源命名不足时可能影响 Emby 剧集识别。

“我的追剧”支持**删除追剧**，确认后停止监控并移出列表；保留下载、云端文件、版本规则和 Sonarr 基础元数据，确保正在进行的下载仍可导入、归档及按保留期清理。使用 Sonarr 原生 `cinema-unfollowed` 标签持久保存移除状态，不删原生 Series；再次明确选择版本追更会移除此标记并恢复所选范围。

后续更新、补集、指定季、单集下载和恢复监控都验证有效规则。没有匹配就等待；原生规则被停用或改动时提示修复。“我的追剧”中，从未保存版本的剧显示“待选版本”，已保存但 Sonarr 规则或专属标签被改动的剧显示“规则异常”；两种情况都在该行直接提供“选择版本”按钮，规则恢复有效前不显示选集下载和追更范围。保存追更范围或版本后列表立即刷新。手动换版须明确确认，默认保留已下载及正在下载内容；不升级或自动删除旧文件。规则信息保存在私有 `state/uploader/versions.json`，原生标签/Profile 保存在 Sonarr；两边均应备份，重启后回读验证。升级前已有的剧集需先选择版本，才能从定制页启动新下载或追更；不会猜测或偷偷套用规则。

这些规则只保证**标题同时符合已确认条件**。站点副标题的“中字”不能作为原生标题条件，也不能证明实际内嵌音轨／字幕；没有标题标记时明确不限，不宣称完整版本已锁定。Sonarr 无法识别的综艺或集数映射会提示自动追更暂不可用，且不把资源错误提交到电影下载器。


设置页实时核对云盘挂载、下载器登录/分类、搜索站点、追剧目录/下载器/站点同步及保留时间，支持切回窗口自动刷新和点击顶部“刷新”手动复查。未完成或连接异常的项目显示黄色感叹号、缺项和处理建议；导航及页面顶部同时提示。默认有效的保留时间视为已配置，不要求重复保存。完成设置后重新检查并清除对应提示。

## 全局主题与中文剧名

顶部可切换深色/亮色；Emby 顶栏也提供同一开关，使用 Emby 自带亮色样式。选择保存在当前浏览器，同一域名的已打开页面自动同步；其他设备及 Emby 原生客户端不受影响。

Sonarr 的剧集元数据通常返回英文主标题。现在复用 Emby 的中文元数据提供方，按 TVDB/TMDB ID 核对身份，优先显示中文名和简介，保留英文原名；没有可核对中文结果时保留原名，不猜译。

## 云端归档

采用 OpenList 原生后台上传：先完整缓存到 VPS，再由云盘任务执行；显示后台进度、具体错误与重试时间。新挂载默认启用阿里云盘官方秒传，命中同内容时可避免完整网络传输，未命中仍正常上传。提交队列成功不等于归档成功，必须等待任务成功并刷新核对云端大小/SHA1，之后才发布。重启继续查询同一任务，避免重复发送整部影片。

缓存需要额外一份文件的磁盘空间；提交前要求文件大小加 2 GiB 可用空间。当前部署 OpenList 缓存与 uploader 状态位于同一宿主文件系统，若单独迁移缓存目录，必须同步调整空间检查。慢速云盘链路仍会限制未命中秒传的上传速度。当前测试 VPS 经受控测试后仅对 OpenList 启用 BBR；配置保存在 VPS 专属 compose.override.yaml 和系统模块加载文件，迁移时应一并记录，通用包不强行修改其他服务器的网络算法。终止/失败的后台任务应在 OpenList 任务页面检查，不会阻断其他文件归档；不自动发布未知状态的旧暂存。

## VPS 状态

磁盘读取 `/media` 所在的宿主文件系统，内存读取宿主 `/proc/meminfo`，CPU 读取宿主 `/proc/stat` 两次采样的差值（扣除 idle/iowait，不重复计入 guest）。默认每 10 秒刷新；第一次 CPU 显示采样中，读取失败显示不可用。没有 Docker Socket、特权模式、宿主 PID 命名空间或监控数据库。

## 自动清理

默认从 qB 的下载完成时间起保留 7 天，范围 1–3650 天，0 关闭。上传成功不会提前删除，上传失败不会因到期强行删除。每轮上传结束后检查，通常一分钟一轮；单个大文件上传期间可能延后。

清理必须满足：

- 本包拥有的 `cinema-movies` / `cinema-tv` / `sonarr-tv` 分类，已完成且时间已到。
- 全部已下载视频都有 SQLite `published` 记录，本地 SHA1、大小与发布凭证一致，云端重新查询验证成功。
- 文件全部位于对应下载根目录，无路径穿越、符号链接或其他种子共享的文件。
- 只有 NFO、常见图片和字体可以随种子清理而无需归档凭证。样片名或位于样片目录的视频同样需要归档凭证，无论文件大小。发现未归档的独立音轨、其他格式字幕、字幕压缩包或其他无法识别的文件时，保留整个种子。需要时可在下载任务中用“同时删除 VPS 本地文件”手动确认删除。
- 电视剧必须能通过硬链接确认 Sonarr 导入副本与下载源是同一个文件；先取消对应集数监控，通过 Sonarr 删除导入副本，再通过 qB 删除任务和下载数据。非硬链接导入或关联不明时保留任务。Sonarr 删除导入副本时可能同时删除关联附件，删除前会检查这部剧的完整目录，包括子目录。若有无法证明归属的其他字幕或附件，即使到期也会保留下载；请查看设置中的清理原因。

清理计划持久化，重启会复核后重试；修改保留时间或关闭设置也作用于未完成计划。自动保留期清理不删除云端文件；手动“删除所有”另行明确确认。qB 做种随任务清理而结束；设置页提示管理员按 PT 要求延长天数。保留未归档任务与失败暂存，磁盘仍可能满，需要管理员处理；不会为了腾空间删除唯一副本。

`state/uploader/data/uploads.sqlite3` 同时保存上传和清理凭证，务必备份。不要手动修改 `published` 或清理计划。

## 更新已有部署

把新源码包解压到独立目录，在 Debian 执行：

```bash
sudo bash /新源码目录/scripts/update_portal.sh /opt/cinema
```

脚本先为本地应用镜像打回滚标签，并备份旧源码、私有配置和状态。SQLite 使用在线快照，备份保留原数据库属主和权限。随后脚本停止 portal/uploader，按发行清单复制源码并设置容器所需的读取权限。第一次安装上传实例标记时，会先确认没有进行中的上传，再重建一次 OpenList；后续更新保持 OpenList 运行。随后构建并启动 portal/uploader/relay。如果网关原先在运行，脚本用本次发行的网关镜像验证配置，应用镜像并等待 Caddy 确认重载。未开启公网的部署保持关闭。失败时恢复旧源码和旧应用镜像，数据库保留当前状态；备份可用于人工恢复。新增数据库字段采用兼容加列，不引入迁移框架。原有账号、站点凭据、媒体和机器级 Compose override 保留。

更新前会核对 Compose 容器的部署目录。源码按发行清单更新，回滚也会移除失败版本新写入的发行文件。首次升级旧安装时，清单未知的文件保留。原有 OpenList 播放令牌会复制到 relay 的专用挂载目录，后续在门户换令牌时自动读取新值。

备份含私有凭据，权限为 0600，保存在部署目录 backups。OpenList 缓存也在 state 内，请预留备份空间。人工恢复 SQLite 时，停掉使用该数据库的服务，把快照连同属主和权限还原到空目录，检查完整性后再切换，避免旧 WAL 被重放。若旧镜像无法打回滚标签，脚本在停服务前退出，请先确认能从备份恢复该运行版本。若升级提示有上传未结束，等待其完成后重跑。

## 恢复与空间保护

- OpenList 正在取消、正在失败及内部重试时继续观察；最终失败最多自动重传 4 次，连同首次最多 5 次。手动取消后使用“重新上传”。旧暂存目录保留，不发布未验证内容。
- OpenList 4.2.9 的上传任务不持久化。启动标记确认实例已经更换后可安全重传。请求响应丢失时按唯一暂存路径查任务，也可凭完整云端 SHA1 恢复。任务 ID 按名称找回，或升级前的上传任务尚未发布且未记录 ID 来源时，要核对云端 SHA1 与源文件匹配后才发布。无法证明完成或结束时保持等待。
- 云端已发布剧集记录 TVDB、季和集。清理本地后仍显示“云端已有”，补集及选集不会重复请求它们。同名外挂 srt/ass/ssa 与视频归档，字幕尚未发布时不发布视频；sample 和原盘文件不自动归档。
- 手动提交下载会计算已有下载、上传缓存和安全余量。后台每 10 秒检查自动追剧下载，必要时暂停最新下载；只恢复空间保护暂停的任务，手动暂停的任务保持不动。空间恢复自动继续需额外 1 GiB 余量。
- 我的追剧中文名采用已校验的提供方 ID；没有中文元数据时显示原名，不猜译。查询成功但没有中文名缓存 24 小时，服务失败短暂缓存。
- 高级管理公网入口复用影院管理员登录，不覆盖 OpenList 的 Authorization。人类登录密码不保存在会话中。OpenList Token 和 qB 服务凭据仍需保存在权限受限的服务配置中。


## 项目分组与任务操作（2026-11-03）

“下载与归档”按 Sonarr 的剧集 ID 关联到稳定的 TVDB ID，同一追剧的单集、季包、不同下载资源显示为一个总条目。展开“查看文件”查看资源包和文件。电影与独立下载仍各自显示，不根据相似标题强行合并到追剧。

- 总条目的项目按钮作用于整部追剧。打开「资源详情与操作」可单独暂停、继续、取消或删除一个资源包，即使该剧目前只有一个种子。合集操作影响包内全部文件。子资源正在处理或等待核对时，整部追剧的冲突操作会暂时禁用。
- 单资源取消会记录该次关闭监控的集数。继续时会校验下载实例和剧集归属，恢复这些集数原有的监控。旧记录缺少监控依据时只恢复下载。页面提示「重试继续」时，可用同一操作重新核对下载器和追更服务。
- 暂停项目会暂停现有下载及该剧后续追更，已开始的上传可以继续完成；继续时恢复原监控状态。恢复追更前验证版本规则，继续已有资源不会改换版本。
- 取消会停止下载和尚未发布的上传，保留文件，支持继续。取消过程中先确认云盘任务已结束，状态不明时保留源文件并显示等待原因。
- 删除提供“保留 VPS 本地文件”“同时删除 VPS 本地文件”“删除所有（含云端原件）”三种范围。默认保留本地文件；前两种保留云端影片，第三种在核对归属后联动清理云端与索引。整个追剧项目删除后也从“我的追剧”移除。
- 仅删除条目后，该资源停止自动管理；此前明确保留的本地文件不会被后来其他条目的删除操作顺带清理，需自行管理。
- 选择删除文件时，核对服务端列出的 VPS 文件和云端原件，再点击确认。成员变化会刷新清单并要求重新确认。后台重启后按已确认的身份继续处理。遇到旧版请求缺少清单、文件被替换或归属证据不足时，可重新确认，或选择“保留剩余文件并结束”。
- 自动清理按当前种子的下载实例计算保留期。重新下载后的文件重新计时；明确选择保留时，后台会撤销该实例以前的清理计划。常规本地清理保留发布凭证，避免今后补集重复下载。

顶部“看片”复用当前 Emby 用户会话，每次在新标签页打开 Emby，避免覆盖正在播放的窗口。会话只通过校验来源和窗口的 postMessage 交接，不放进网址，也不传递 OpenList/qB 管理密钥；同时支持 HTTPS 同域及 SSH 隧道的 8097→8095 端口切换。浏览器需要允许此站点打开窗口和使用本地存储。

验证命令：`python -m unittest discover -s tests -q`、`node tests/search-entry.test.cjs`、`node tests/watch-handoff.test.cjs`、`node tests/task-controls.test.cjs`、`node tests/portal-resilience.test.cjs`。真实测试只删除自建资源，不用已有影片测试删除按钮。


## 任务显示与下载进度

单文件资源直接显示状态和操作，不再折叠；独立下载的单个文件在上传前不再重复显示一行相同的状态和进度。多文件项目保留“查看文件”。下载未完成时，已完成的文件显示“下载已完成”；下载完成后，追剧项目显示“等待导入”（等待 Sonarr 导入），其他下载显示“等待上传”，`.nfo`/海报等非视频字幕附件显示“不自动归档”；资源里没有可自动归档的视频（例如原盘或只有附件）时显示“未发现可归档视频”，这类文件需要手动处理。等待自动重试的上传条目会显示“下次重试”时间。总条目持续显示当前已添加资源的总大小、实时下载速度（活动下载时）以及下载百分比和进度条，包括完成后的 100%。多资源按体积加权，新增后续集数时进度会相应更新；下载 100% 后仍需完成上传、校验和发布。

下载未完成时显示暂停／继续、取消下载；下载完成但尚未发布时显示取消归档（已取消时可继续归档）。全部发布后仅显示做种状态及删除操作。已发布资源仍可能在 qBittorrent 中保留做种，直到本地保留期结束。

“看片”位于顶部主导航“找片”的左侧，继续复用 Emby 会话。

## Emby 默认刮削

首次管理员登录自动创建电影、电视剧两库并应用中文默认配置，成功后持久保存初始化标记；后续登录及服务重启不重复覆盖手动调整。初始化失败不阻止登录，黄色提示列出 Emby 刮削未完成，可重试。“设置 → Emby 海报与简介 → 应用推荐刮削设置”保留为手动恢复入口，复用当前管理员会话，不要求再次输入密码。已有库保留名称和路径，遇到混合目录或类型冲突时停止。

默认中文、中国地区，TMDB 优先，TVDB 等已安装默认来源补充。海报预先下载，元数据保存在 VPS 的 `state/emby`；不写云端 NFO/海报，不做视频截图、章节缩略图或片头检测。应用时只补充缺失资料和图片，保留已有手工修改与海报；之后新影片随 Emby 扫描自动刮削。中文资料是否齐全取决于提供方，无法可靠识别时应在 Emby 按 TMDB/TVDB ID“识别”，不使用站点副标题猜配。

## 播放记录与直连证据

顶部“播放记录”显示最近 100 次经影院入口发起的播放，每 10 秒刷新，仅管理员可见。

- **网盘直连跳转**：视频或云端转码分片实际返回 302/307 等跳转，目标为已识别的阿里云盘/CDN 域名。页面显示状态码与域名，不保存完整签名地址。
- **客户端播放进度**：由 Emby 原生播放上报关联到同一客户端、影片与播放会话。下发直链与播放成功分别展示；没有有效进度时不会标记播放成功。
- **VPS 中转**：观察到影院入口实际返回视频字节时告警。播放列表、海报、字幕和登录等控制数据经过 VPS 不属于视频中转；页面不把 Emby 的 DirectPlay/DirectStream/Transcode 标签作为链路证据。
- **直连尚未确认／请求失败**：没有视频跳转证据或出现错误时保留未知、错误状态，不猜测成功。长时间没有新上报时显示“暂无近期上报”。

严格播放策略继续禁止回源传输 Emby 视频正文，取链失败不会自动退回 VPS 中转。云端转码的播放列表仍经影院协调，视频分片应跳转 CDN。只记录本次升级后经 relay 的请求；直连原始 Emby 端口或绕过本服务的播放不会出现在此处。

记录位于 `state/relay/lib/playback`，两份约 2 MiB 的滚动 JSONL，由 relay 写入、portal 只读。进度和同一视频分片路由按 15 秒节流，保留暂停状态变化；不记录账户令牌、完整请求网址或完整网盘直链。历史为有容量上限的运行记录，不保证永久保存。

本次同时修复中文文件名的部分云端版本无法起播：Emby Web 可能将自定义媒体标识中 Base64 的 `+` 变为空格，旧路径解码随后无法匹配该影片而返回 403。共享解码函数会在 Base64 解码时恢复该字符，原始路径保持不变；对应文件的访问权限和路径归属仍须通过验证。

共享响应缓存保持关闭时，选中的云端版本也会明确返回 HLS 播放声明，避免被当作普通 MP4 串流而解析失败。这里的“转码”由网盘提供，未开启 Emby 的 VPS 转码权限。原画与 FHD 云端转码均已在真实网页播放器验证，视频或分片响应来自阿里 CDN，记录与客户端进度成功关联。

虚拟视频索引优先使用 OpenList 返回的真实时长，无需在 VPS 下载视频探测。旧版索引统一使用 3 小时，会让实际已到片尾的影片仍显示“恢复播放”，点击后立即结束。升级前已经生成的占位索引需要备份后修正时长，再让 Emby 刷新媒体信息；不要删除云盘文件或重建整个媒体库。网盘暂未提供有效时长时仍保留上游的 3 小时估值，须在元数据就绪后重新生成该索引；遇到立即结束可先选择“从头开始”。


## 首页站点近期热种

找片首页从 Prowlarr 已启用的 PT 站点读取近期资源列表，分别显示 6 部热门电影、6 部热门剧集／综艺。按做种人数排序，同一 IMDb 条目合并多个版本。点击片名立即复用正常搜索入口，不会直接开始下载。

热门片名优先使用同站点、同资源 ID 对应的中文副标题，去掉别名、集数和版本说明；目前复用 HDSky、SpringSunday 的列表解析。每个入选站点只读取一页近期列表，与热种一起缓存。没有对应中文信息或站点读取失败时保留原名，不猜译。点击继续使用原英文关键词搜索，完整资源名保留在悬停提示中；中文名称只影响首页展示，不参与 Emby 的影片识别。

这是每站最多 100 条近期列表中的排序，不是全站完整热榜；站点固定、置顶和分类能力会影响结果。每 30 分钟缓存一次，失败短暂缓存 1 分钟；禁用站点后不再展示其缓存。浏览器不接收 Cookie、管理密钥、种子链接或下载 passkey。未配置站点或站点失败时仍可正常输入搜索。

## 中文字幕默认值

新装首次管理员登录时，尚未配置字幕语言的媒体库默认选择简体、繁体中文，启用已安装且默认开启的字幕来源，不限制影片年龄，不要求媒体文件哈希完全匹配，也不因音轨语言或内嵌字幕而跳过。由于云端媒体库是只读索引，自动字幕保存在 Emby 配置目录，不写入云盘占位目录。

仍须在 Emby → 插件中配置字幕提供方账号，之后由 Emby 的 Download Subtitles 计划任务按可用字幕下载。选择语言不等于提供方已有匹配文件；放宽哈希匹配后可能需要手动校准字幕版本。已有非空字幕语言的库保留整组手工字幕偏好；已有初始化标记的部署不会在升级或登录时重新应用。

## 相同种子名与集数显示

不同种子哈希可能使用相同的整季资源包名，但只下载各自选中的不同集数。追剧项目优先显示实际文件中的 SxxExx 集号，完整种子名、文件名及单资源操作在“资源详情与操作”内。项目仍以真实种子哈希、归档任务 ID 关联，不能按同名自动合并或删除。

## 下载到自己的电脑或手机

这里的“下载到设备”与找片页把 PT 资源下载到 VPS 是两件事。

- **VPS 本地文件**：用现有 SSH 账号通过 SFTP（例如 WinSCP）连接部署服务器，进入安装目录下的 `media/downloads/movies`、`media/downloads/tv`、`media/downloads/tv-manual`；Sonarr 导入副本在 `media/library/tv`。只取已完成的文件。服务器默认安装目录是 `/opt/cinema`。不要取 `state/library` 的小型占位索引，那里不是完整视频。自动清理后本地副本可能已移除，可从云盘下载。
- **阿里云盘文件**：设置 → 高级管理 → OpenList，进入 `/aliyun/Movies` 或 `/aliyun/TV`，选文件后下载；也可以直接用阿里云盘电脑／手机客户端。
- **Emby 片库文件**：本项目 Emby 展示的是同一份阿里云盘影片，不是第三份视频。当前严格配置 `download-strategy: "403"` 明确禁用了 Emby 下载接口，需通过上述 OpenList 或阿里云盘下载原件。原生 Emby Web 支持单文件下载，手机 App 的离线同步属于另一功能，不能把两者混同；本轮没有开放当前禁用的下载路由。

其他媒体服务器可考虑 Jellyfin；它也支持 Open Subtitles。Bazarr 是配合 Sonarr/Radarr 的字幕管理器，不是电影墙服务器。当前基于 Emby 的登录、媒体索引和直连适配需要另外验证迁移，不能只替换镜像。本轮没有安装额外服务。


## 删除后换版与旧索引

从阿里云盘删除旧影片后，relay 默认不自动删除本地占位索引（`auto-remove-max-count: 0`），以保留云盘短时异常时的片库。新版本文件名不同会生成新索引；旧、新索引可能被 Emby 按同一影片合并为一张海报，文件夹或版本列表仍显示两项。失效旧版本可能被默认选中而取链失败。

现在可使用下载任务中的“删除所有”完成联动清理。需要手工整理时，确认云盘父目录刷新成功、旧对象已不存在、新对象完整可用后，应备份并移出对应的旧本地占位目录，再扫描电影库；不要把云盘请求失败直接当作删除证据。保持现有关闭自动删除的策略。本次 Resident Evil 仅移出旧 KyoGo 的 331 字节索引，保留新 HONE、云盘原件及观看进度。

严格直连鉴权支持 Emby 返回的多版本组：组内允许有各自的 ItemId，但仍须包含当前请求对应的影片，云端路径仍须属于该用户获准播放的 MediaSources。未授权的影片和组外路径继续拒绝。


## 删除所有与重新下载

下载任务 → 删除 → 选择“删除所有（含云端原件）”。默认仍选择保留 VPS 文件。确认框会列出所选项目／资源的云端目标；整个追剧项目会包含该项目内所有资源，若只换一个版本，应在对应资源的“资源详情与操作”中删除。

后台先结束上传并停止做种，验证当前下载任务、文件关联、云盘文件大小／SHA1 和本地索引边界，再删除所选版本的已归档云端视频及字幕，清理确认为空的云端目录，将占位索引移到私有状态目录的 `deleted-indexes` 备份中，扫描 Emby 并回读确认来源已消失，最后删除 VPS 下载／导入副本和任务记录。失败保持“删除处理中”并显示原因，后台自动复核重试；请求成功不直接等同于删除成功。云盘故障、文件被替换、共享本地文件或索引异常时保留相关文件。

完成后解除已删除归档的路径占用和已归档集数记录，允许重新下载同一资源或另一版本。同一影片未被选中的版本保留；既有“只删除条目”和“同时删除 VPS 文件”仍保留云端影片。删除所有会停止做种，云端删除不能在此页面撤销，需先满足 PT 站要求。

首次使用会通过当前管理员创建或复用专用 `Cinema library maintenance` Emby API 密钥，仅写入私有服务配置，供后台扫描及回读使用，不返回浏览器。重新连接云盘或运行 setup 保留该配置。uploader 的媒体和索引挂载允许写入，以处理已失去下载任务关联但可按归档 SHA1 核实的本地副本；其他容器权限保持原状。云端隔离上传区中的未知或未确认残片仍保留，避免误删正在结束的上传。
